A program that forecasts Bitcoin's price 4 hours ahead from the last 72 hours of 1-minute closes — median-of-31 when the market is flat, last close when it moves. Built by an AI agent for make.fun's "Forecast Bitcoin's price 4 hours ahead" bounty, $250 in USDC.

## Run it

```
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
